### الميزات التجريبية والمستهدفة
مسار تصميم المطابخ: الغرفة، الفتحات، الخزائن، الرخام، الأجهزة، الإكسسوارات، الإضاءة، المواد، العرض ثنائي وثلاثي الأبعاد، الحفظ والتصدير. لا تزال بعض وظائف الواجهة وإخراج التصنيع بحاجة إلى اعتماد إضافي.

### حدود الاختبار
- نجح اختبار تشغيل البرنامج المجمد ثلاث مرات، ونجح اختبار مسار GPU وCPU مرتين.
- نجح مثبت QA المختلف في 18 مرحلة ضمن Windows Sandbox. لكن ملف QA لا يعمل على Windows العادي ولم يُنشر.
- مثبت BETA الحالي لم يُعتمد بعد باختبارات التثبيت/الترقية/التراجع الكاملة.
- نسبة معايير القبول المسجلة: 86% مثبتة، و14% معلقة.
- الملف غير موقّع رقميًا؛ قد يظهر تحذير SmartScreen.
- احتفظ بنسخة احتياطية للمشاريع واستخدم جهازًا للتجربة فقط.
- لا تستخدم ملفات CNC أو قوائم القطع والمواد أو القياسات للتصنيع قبل اعتماد مستقل من فني مؤهل.
