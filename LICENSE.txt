This is a pre-release BETA build supplied for voluntary evaluation.
It installs side-by-side under the current user's Local AppData folder and
does not replace earlier Kitchen CAD installations.

The installer has not received final production acceptance, Authenticode
code signing or Windows in-place upgrade certification. Windows SmartScreen
may warn about its unsigned publisher. Back up important projects before
testing. Do not use unfinished CAD/CNC output as manufacturing instructions.

All CNC drafts, cut lists, BOM outputs and estimates require independent
review and approval by a qualified workshop professional for the actual
machine, material, controller and postprocessor before fabrication.
