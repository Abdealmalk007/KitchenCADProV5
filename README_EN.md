# Kitchen CAD Pro V5 RC6 - Experimental Beta

Download: https://github.com/Abdealmalk007/KitchenCADProV5/releases/download/v5.0.0-rc6-beta/KitchenCADProV5_RC6_BETA_Setup.exe

This is an unsigned preview installer for voluntary evaluation, NOT a production-certified release. It supports side-by-side per-user installation. The separate QA installer is restricted to Windows Sandbox and is not the public download.

RC6 frozen-app smoke tests were 3/3 PASS and GPU/CPU fallback tests 2/2 PASS. The different QA Sandbox installer passed 18/18 stages, but the BETA installer has not passed a matching host installation/upgrade/rollback acceptance cycle. Project acceptance at packaging: 86% verified, 14% pending.

Back up designs and test on a spare machine. Manufacturing, CNC, cut lists, BOM and actual dimensions require independent validation by a qualified workshop professional. Unsigned Authenticode status may result in SmartScreen warnings.
